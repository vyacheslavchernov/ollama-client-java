### Сборник примеров использования API Ollama

 - chat - пример чата с агентом в ходе которого удерживается контекст диалога + использование инструментов
 - generate - примеры простой генерации без удержания контекста
 - misc - пример запроса дополнительной информации об Ollama
 - models - пример запросов информации о моделях доступных в Ollama (список доступных, загруженных в память, запрос доп. информации о моделях). Примеры поиска моделей по различным параметрам.
